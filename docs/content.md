# Генерация контента

## Структура

- основное приложение
- утилита синхронизации
- шаблон генерации контента
  - с файлом `settings.json` со всеми настройками
  - со скриптом (расширение `.jsx` или `.jsxbin`) сборки проекта в After Effects (AE)
- при рендере на удаленных серверах (авторендере) еще есть скрипт авторендера (`asyncScript-v.js`).

## Общая схема работы

- Открывается утилита синхронизации. Вводятся необходимые данные того аккаунта, с которым будет синхронизация – `Токен`, `Домен`. Указывается путь к папке `data` с папками слотов внутри. При авторендере указывается путь к скрипту авторендера. Запускается синхронизация
- После запуска синхронизации, файл `settings.json` попадает в основное приложение.
  В основном приложении, согласно блокам этого файла, из `content#`, создаются блоки в интерактиве. (Слайд-шоу, Видео подложка и т.д.). Созданные блоки наполняются контентом – текстом, изображениями и т.д. Происходит публикация нажатием кнопки «Опубликовать» или «Старт рендер». Меняется дата публикации.
- После публикации контента, заполненные блоки в `settings.json` в поле `blocks` попадают в утилиту синхронизации. Утилита скачивает необходимые файлы и удаляет файлы прошлой публикации. После этого, либо запускается скрипт авторендера и в интерфейсе приложения получаем итоговое видео, либо необходимо открыть AE, запустить скрипт сборки проекта и после сборки срендерить итоговое видео.

## Файл `settings.json`

```
{
    "id#": "newsStandartThreeSlots",
    "path": "D:\\iactive.pro_News_three_slots_new\\iactive.pro\\data\\newsStandartThreeSlots",
    "name#": "Новости (стандарт) 3 слота",
    "type#": "news",
    "blocks": [...],
    "content": [],
    "content#": {
      "slideShow": {...},
      "videoAndPhoto": {...},
      "videoBackground": {...}
    },
    "contentId": "7485",
    "aspect_width": 16,
    "blocksCount#": "0",
    "publish_time": "2025-07-16 17:40:07",
    "aspect_height": 9,
    "renderGroupId": "h0VnXNbqVG",
    "isRenderServer": "false",
    "numberLinesTitre": "3"
  }
```

| параметр         | тип    | описание                                                                                                                            | пример значения          |
| ---------------- | ------ | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| id#              | строка | ID слота шаблона. Должен быть уникальным для каждого шаблона (клиента), если несколько слотов в одном шаблоне, то для каждого слота | "newsStandartThreeSlots" |
| path             | строка | Путь к файлу settings.json в папке data на устройстве                                                                               |                          |
| name#            | строка | Имя слота, отображаемое в интерфейсе приложения                                                                                     | "Новости (стандарт)"     |
| type#            | строка | Тип слота, отображаемый в интерфейсе приложения                                                                                     | "news"                   |
| blocks           | массив | Массив заполненных блоков контентом, в интерфейсе приложения                                                                        |                          |
| content          | массив | Набор элементов для старых шаблонов с одним блоком                                                                                  | []                       |
| content#         | объект | Объект c блоками без контента, с их параметрами и наборами элементов для каждого блока                                              |                          |
| contentId        | строка | ID интерактива, добавляется на беке                                                                                                 | "7339"                   |
| aspect_width     | число  | Горизонтальный коэффициент пропорции соотношения сторон кадра при кадрировании изображений                                          | 16                       |
| blocksCount#     | строка | Минимальное кол-во блоков для публикации                                                                                            | "0"                      |
| publish_time     | строка | Дата и время публикации контента                                                                                                    | "2025-07-04 13:02:39"    |
| aspect_height    | число  | Вертикальный коэффициент пропорции соотношения сторон кадра при кадрировании изображений                                            | 9                        |
| renderGroupId    | строка | ID группы рендеров на удаленных серверах. Добавляется на беке                                                                       | "0unfR9yr6h"             |
| isRenderServer   | строка | Публикация с рендером на удаленных серверах                                                                                         | "false"                  |
| numberLinesTitre | строка | Количество строк в одной пачке текста в элементе "stringWithPreviewElement"                                                         | "3"                      |

### Поля блоков без контента в `content#`

```
"content#": {
    "slideShow": {
      "label": {
        "en": "Slide show",
        "ru": "Слайд-шоу"
      },
      "fields": [...],
      "canSelect": true,
      "isAutoCreate": false
    }
}
```

| параметр     | тип        | описание                                                 | пример значения                        |
| ------------ | ---------- | -------------------------------------------------------- | -------------------------------------- |
| label        | объект     | Название блока на двух языках                            | {"en": "Slide show","ru": "Слайд-шоу"} |
| fields       | массив     | Набор элементов блока                                    |                                        |
| canSelect    | логический | Доступен ли блок для создания в интерфесе приложения     | true                                   |
| isAutoCreate | логический | Создается ли блок автоматически при создании интерактива | false                                  |

### Общие поля элементов в `fields`

```
  "fields": [
    {
      "label": {
        "en": "Caption",
        "ru": "Заголовок"
      },
      "name#": "caption",
      "order": "1",
      "type#": "string",
      "isOptional": false,
      "max_length#": "35"
    }
  ]
```

| параметр    | тип        | описание                                                                  | пример значения                |
| ----------- | ---------- | ------------------------------------------------------------------------- | ------------------------------ |
| label       | объект     | Название элемента на двух языках                                          | { "en": "Text","ru": "Текст" } |
| name#       | строка     | Имя элемента, по нему хранятся данные заполненного элемента в blocks      | "text"                         |
| order       | строка     | Порядковый номер элемента в блоке                                         | "2"                            |
| type#       | строка     | Тип элемента, для отображения в интерфейсе приложения                     | "stringWithPreviewElement"     |
| isOptional  | логический | НЕобязателен ли этот элемент к заполнению                                 | false                          |
| max_length# | строка     | Для текстовых элементов максимальная длина текста в интерфейсе приложения | "550"                          |

### Дополнительные поля элементов в `fields`

#### Элемент `type#:stringWithPreviewElement`

```
 "fields": [
    {
      "label": {
        "en": "Text",
        "ru": "Текст"
      },
      "name#": "text",
      "order": "2",
      "type#": "stringWithPreviewElement",
      "fontSize": 40,
      "textWidth": 1350,
      "fontFamily": "Montserrat",
      "fontWeight": 600,
      "isOptional": false,
      "isUpperCase": true,
      "max_length#": "550",
      "text_effects": [
        {
          "id": 1,
          "type": "color",
          "value": "#00a5d3"
        },
        {
          "id": 2,
          "type": "color",
          "value": "#00DC6B"
        }
      ]
    }
  ]
```

| параметр     | тип        | описание                                                                                                                                                  | пример значения                              |
| ------------ | ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| fontSize     | число      | Размер шрифта текста в AE (px)                                                                                                                            | 40                                           |
| textWidth    | число      | Ширина плашки с текстом в AE (px)                                                                                                                         | 1350                                         |
| fontFamily   | строка     | Семейство шрифта в AE (в интерфейсе подключены "Montserrat", "Roboto", при использовании других шрифтов необходимо подключить их в интерфейсе приложения) | "Montserrat"                                 |
| fontWeight   | число      | Жирность шрифта в AE                                                                                                                                      | 600                                          |
| isUpperCase  | логический | Текст в верхнем регистре в AE                                                                                                                             | true                                         |
| text_effects | массив     | Набор акцентных цветов                                                                                                                                    | {"id": 1,"type": "color","value": "#00a5d3"} |
